# 소금 소리탐험대

초등 국악 수업용 소금 음정 연습 웹앱입니다. 웹 브라우저에서 마이크로 들은 소리의 주파수를 분석하고 선택한 율명과의 차이를 cent와 0~100점으로 보여 줍니다. 노래방처럼 일정 시간 안정적으로 유지된 기본음만 평가하므로, 세게 부는 소리의 배음과 순간 흔들림은 점수에 반영하지 않습니다. 국악기의 자연스러운 음정 폭을 고려해 목표음의 약 ±55 cent는 ‘올바른 소리’, 약 ±100 cent는 ‘좋음’으로 판정합니다.

음정 표시는 약 1초 동안 이어진 소리의 중앙값을 사용하므로, 순간적인 입김 변화에는 약 10배 덜 민감하게 반응합니다.

## 사용 방법

1. `index.html`을 Chrome 또는 Microsoft Edge에서 엽니다.
2. 율명(임·남·무·황·태·고·중)을 고릅니다.
3. **기준음 듣기**로 목표 소리를 확인한 뒤, **마이크 켜고 연습 시작**을 누릅니다.
4. 브라우저의 마이크 사용을 허용하고 1초 이상 고르게 불면 실시간 점수와 평균 점수가 표시됩니다.

### 실제 소금 소리로 기준음 맞추기

1. 기준으로 삼을 율명을 선택하고 **내 소리로 기준 맞추기**를 누릅니다.
2. 마이크를 켠 후 **이 음 저장 시작**을 누르고, 해당 음을 약 1초 동안 고르게 붑니다.
3. 안정된 음의 주파수가 저장되며 버튼에 ✓가 붙습니다. 7개 율명을 각각 저장할 수 있습니다.

저장한 값은 같은 브라우저에 남아 다음 수업에서도 사용할 수 있습니다. 필요하면 ‘저장한 기준음 모두 지우기’를 누르세요.

마이크는 보안상 일반적으로 `localhost` 또는 HTTPS에서 가장 잘 작동합니다. 파일을 바로 열었을 때 권한이 차단되면, 학교의 웹서버/학습관리시스템에 이 폴더를 올리거나 로컬 웹서버로 열어 주세요.

## 음계 기준

기준 주파수는 다음과 같이 고정되어 있습니다: `임 483 Hz · 남 545 Hz · 무 590 Hz · 황 660 Hz · 태 740 Hz · 고 828 Hz · 중 894 Hz`. **기준음 듣기**는 피아노가 아니라 소금의 숨결 섞인 관악기 음색을 모사해 들려줍니다.

## 유의 사항

- 한 명씩, 비교적 조용한 곳에서 사용하면 인식이 좋아집니다.
- 이 앱은 음정 연습 보조 도구이며 운지·호흡·음색 평가는 교사가 함께 지도해 주세요.
